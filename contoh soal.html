Metode 1

Metode Eliminasi (Menghilangkan Variabel)

🔢 Soal Biasa
Carilah himpunan penyelesaian dari: $$\begin{cases} 2x + 3y = 8 \\ 3x - y = 1 \end{cases}$$

Langkah 1: Eliminasi $y$ (Kalikan persamaan kedua dengan 3)

$2x + 3y = 8 \quad (\times 1) \rightarrow 2x + 3y = 8$

$3x - y = 1 \quad (\times 3) \rightarrow 9x - 3y = 3$

---------------------------- (+)

$11x = 11 \rightarrow \mathbf{x = 1}$


Langkah 2: Eliminasi $x$ (Samakan koefisien $x$)

$2x + 3y = 8 \quad (\times 3) \rightarrow 6x + 9y = 24$

$3x - y = 1 \quad (\times 2) \rightarrow 6x - 2y = 2$

---------------------------- (-)

$11y = 22 \rightarrow \mathbf{y = 2}$

Jadi, $\mathbf{HP = \{(1, 2)\}}$.

📝 Soal Cerita
Andi membeli $3$ buku dan $2$ pensil seharga Rp$14.500$. Budi membeli $2$ buku dan $1$ pensil seharga Rp$9.500$. Berapa harga $1$ buku ($x$) dan $1$ pensil ($y$)?

Model Matematika:

$$\begin{cases} 3x + 2y = 14.500 \\ 2x + y = 9.500 \end{cases}$$

Eliminasi $y$:

$3x + 2y = 14.500 \quad (\times 1) \rightarrow 3x + 2y = 14.500$

$2x + y = 9.500 \quad (\times 2) \rightarrow 4x + 2y = 19.000$

----------------------------------------- (-)

$-x = -4.500 \rightarrow \mathbf{x = 4.500}$ (Harga Buku)


Eliminasi $x$:

$3x + 2y = 14.500 \quad (\times 2) \rightarrow 6x + 4y = 29.000$

$2x + y = 9.500 \quad (\times 3) \rightarrow 6x + 3y = 28.500$

----------------------------------------- (-)

$\mathbf{y = 500}$ (Harga Pensil)

Metode 2

Metode Substitusi (Mengganti Variabel)

🔢 Soal Biasa
Tentukan nilai $x$ dan $y$ dari: $$\begin{cases} x = 2y + 1 \\ 2x + 3y = 16 \end{cases}$$

Langkah 1: Masukkan pers (1) ke pers (2)

$2(2y + 1) + 3y = 16$

$4y + 2 + 3y = 16$

$7y = 16 - 2$

$7y = 14 \rightarrow \mathbf{y = 2}$


Langkah 2: Masukkan nilai $y = 2$ ke pers (1)

$x = 2(2) + 1$

$\mathbf{x = 5}$

Jadi, nilai $\mathbf{x = 5}$ dan $\mathbf{y = 2}$.

📝 Soal Cerita
Umur ayah ($x$) sekarang adalah $3$ kali umur anaknya ($y$). Jika selisih usia mereka adalah $26$ tahun, berapakah umur mereka masing-masing?

Model Matematika:

$x = 3y \quad$ ... (Pers 1)

$x - y = 26 \quad$ ... (Pers 2)


Substitusikan Pers (1) ke Pers (2):

$3y - y = 26$

$2y = 26 \rightarrow \mathbf{y = 13}$ (Umur Anak)


Cari nilai $x$:

$x = 3 \times 13 \rightarrow \mathbf{x = 39}$ (Umur Ayah)

Metode 3

Metode Gabungan (Eliminasi & Substitusi)

🔢 Soal Biasa
Selesaikan sistem persamaan berikut: $$\begin{cases} 4x + 5y = 17 \\ 2x + 3y = 11 \end{cases}$$

Langkah 1: Eliminasi $x$ untuk dapat $y$

$4x + 5y = 17 \quad (\times 1) \rightarrow 4x + 5y = 17$

$2x + 3y = 11 \quad (\times 2) \rightarrow 4x + 6y = 22$

---------------------------- (-)

$-y = -5 \rightarrow \mathbf{y = 5}$


Langkah 2: Substitusi $y = 5$ ke persamaan kedua

$2x + 3(5) = 11$

$2x + 15 = 11$

$2x = 11 - 15$

$2x = -4 \rightarrow \mathbf{x = -2}$

📝 Soal Cerita
Keliling persegi panjang adalah $44\text{ m}$. Jika panjangnya ($x$) adalah $6\text{ m}$ lebih dari lebarnya ($y$), tentukan ukuran panjang dan lebarnya!

Model Matematika:

$2(x + y) = 44 \rightarrow x + y = 22 \quad$ ... (Pers 1)

$x = y + 6 \rightarrow x - y = 6 \quad$ ... (Pers 2)


Langkah 1: Eliminasi $y$

$x + y = 22$

$x - y = 6$

-------------- (+)

$2x = 28 \rightarrow \mathbf{x = 14\text{ m}}$ (Panjang)


Langkah 2: Substitusi $x = 14$ ke Pers (1)

$14 + y = 22 \rightarrow \mathbf{y = 8\text{ m}}$ (Lebar)
